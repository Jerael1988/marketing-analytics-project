# Marketing Analytics Project: E-Commerce Customer Segmentation & CLV Prediction

## Overview
A complete marketing analytics project analyzing 5,000 e-commerce customers to identify high-value segments and predict Customer Lifetime Value (CLV). This project demonstrates data-driven customer strategy and ROI optimization.

## Key Results
- **RFM Segmentation**: Identified 4 customer tiers (VIP, High-Value, Medium, Low)
- **CLV Prediction Model**: R² 0.6408 with $174 prediction accuracy
- **Revenue Opportunity**: $3.6M potential from top 2,500 customers (50% of base)
- **Email Engagement**: 70% correlation with customer lifetime value
- **At-Risk Recovery**: $1.1M in revenue at risk from dormant high-spenders

## Technical Stack
- **Python**: pandas, NumPy, scikit-learn, Matplotlib, Seaborn
- **Machine Learning**: Random Forest Regressor
- **Analysis**: RFM segmentation, customer clustering, regression modeling
- **Visualization**: Professional dashboards and charts
