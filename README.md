# Marketing Analytics Project: E-Commerce Customer Segmentation & CLV Prediction

## Overview
A complete marketing analytics project analyzing 5,000 e-commerce customers to identify high-value segments and predict Customer Lifetime Value (CLV).

## Key Results
- **RFM Segmentation**: 4 customer tiers identified (VIP, High-Value, Medium, Low)
- **CLV Prediction Model**: R² 0.6408 with $174 prediction accuracy
- **Revenue Opportunity**: $3.6M potential from top 2,500 customers
- **Email Engagement**: 70% correlation with customer lifetime value

## Technical Stack
- Python, pandas, NumPy, scikit-learn
- Random Forest Regressor
- Matplotlib/Seaborn visualizations

## Files
- `01_data_exploration.ipynb` - EDA and RFM analysis
- `02_clv_prediction_model.ipynb` - CLV model training
